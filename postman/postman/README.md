# Postman API Test Collection

This folder includes the Postman collection and environment used to test the Paylocity STE API.

Files:
- 'Paylocity_API_Collection.json' – Full API test suite including happy path, edge cases, and negative tests.
- 'Paylocity_API_Environment.json' – Environment variables for Base URL, auth, and test data.

To run the collection:
1. Import both files into Postman.
2. Set the environment to 'Paylocity_API_Environment'.
3. Run the collection via Postman or Newman.
